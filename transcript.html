Turn 12Usercard A1
Card A1 — security, privacy and fraud review
Asked to run card A1 (security, privacy and fraud review) once A6 was done.
Claude's response

Launched an independent background subagent with no visibility into this conversation — given only CLAUDE.md's invariants, named SPEC sections and backend source — to hunt for location leaks, unearned kadam/earnings, fragile-place pin exposure, pHash bypass, unlabelled ₹ figures, or broken auth. It returned 1 Critical, 3 High, 2 Medium and 1 accepted Low finding.

  • Critical — place_payload's distance_km was computed from a fragile place's true coordinates even when the returned lat/lng had been fuzzed; three readings could trilaterate the exact pin without ever pledging. Fixed by deriving distance from the same (possibly fuzzed) coordinates actually returned.
  • High — /api/touch trusted a client-asserted content_type with no proof anyone watched anything, letting fabricated touches steal a creator's attribution/kadam. Deleted the unverifiable branch, added an hourly rate limit and dedupe.
  • High — Uvicorn's access logger printed every request's full query string, including live lat/lng, to plaintext logs. Disabled uvicorn.access at import time.
  • High — check_in's visit checks were a plain read-then-write with no lock; concurrent requests could double-award kadam. Fixed with a per-(user_id, place_id) threading.Lock; a 5-thread test proved the bug, then the fix.
  • Medium — login's early-exit on a non-existent account skipped the slow argon2id check, a timing side-channel. Fixed with a precomputed dummy hash checked on every attempt.
  • Medium — the dev /teleport endpoint handed back a fragile place's exact coordinates with no pledge check. Fixed to apply the same fuzzing the real API uses.
  • Low, accepted — pHash dedupe can be defeated by a flip/crop/colour-shift; inherent to perceptual hashing, already slated for the Tier-2 CLIP mitigation.

Added security headers (CSP scoped to tiles.openfreemap.org, X-Content-Type-Options, Referrer-Policy, Permissions-Policy, X-Frame-Options). Wrote up every finding in docs/SECURITY_REVIEW.md with one test per fix. Full suite: 238 backend, 26 frontend, all green. Ticked A1, logged in PLAN.md, 3 viva Q&A appended.
